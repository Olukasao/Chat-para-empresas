╔═════════════════════════════════════════════════════════════╗
║ 🔑 ENDPOINTS PRINCIPALES                                  ║
╚═════════════════════════════════════════════════════════════╝

POST   /api/login                        → Autenticar
GET    /api/chat/conversas-diretas       → Listar conversas
GET    /api/chat/conversa-direta/:id     → Mensajes 1a1
POST   /api/chat/enviar-direto           → Enviar mensaje
GET    /api/chat/grupos                  → Listar grupos
GET    /api/chat/grupo/:id               → Mensages grupo
POST   /api/chat/enviar-grupo            → Enviar msg grupo
GET    /api/chat/usuarios                → Listar usuarios
PUT    /api/chat/status/:status          → Cambiar status

║ 🔧 TROUBLESHOOTING RÁPIDO                                 ║
╚═════════════════════════════════════════════════════════════╝

❌ "Port 8600 already in use"
   → lsof -i :8600 && kill -9 <PID>

❌ "Cannot find module"
   → npm install

❌ "No database selected"
   → mysql -u root -p < migration.sql

❌ "CORS error"
   → Verificar URL do frontend em api.js

❌ "Mensagens não aparecem"
   → F12 → Console (procurar erros)

❌ "Socket não conecta"
   → Verificar se backend está rodando

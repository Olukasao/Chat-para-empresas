                           🐛 PROBLEMAS? VEJA AQUI
═══════════════════════════════════════════════════════════════════════════════

Problema: Mensagens não aparecem
  → F12 > Console > Procurar por erros vermelhos
  → Verifique se backend está rodando (npm run dev)

Problema: Port já em uso
  → lsof -i :8600 (backend) ou :5173 (frontend)
  → kill -9 <PID>

Problema: Banco não conecta
  → mysql -u chat -p chat_interno
  → Digite a senha configurada fora do repositorio

Problema: CORS error
  → Verifique em frontend/src/services/api.js
  → A URL deve ser http://localhost:8600/api (em dev)

Problema: Socket não conecta
  → F12 > Console > Procurar por erros
  → Verifique se backend está em http://localhost:8600

Mais detalhes: Leia OPERACAO.md na seção Troubleshooting

   → Cria pasta 'dist' pronta para upload

2. Configurar Backend:
   • npm install -g pm2
   • pm2 start backend/src/server.js --name "chat-api"
   • pm2 save && pm2 startup

3. Setup HTTPS:
   • Gere certificado SSL com certbot
   • Configure nginx como proxy reverso

4. Backup Automático:
   • Configure cron job para mysqldump diário

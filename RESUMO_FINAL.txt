🚀 COMO INICIAR
================================================

PASSO 1: Banco de Dados
-----------------------
$ mysql -u root -p
mysql> source /home/noc/chat-interno/backend/src/db/migration.sql;
mysql> source /home/noc/chat-interno/backend/src/db/seed.sql;
mysql> exit

PASSO 2: Backend
---------------
$ cd /home/noc/chat-interno/backend
$ npm install (se não tiver sido feito)
$ npm run dev

PASSO 3: Frontend
----------------
$ cd /home/noc/chat-interno/frontend
$ npm install (se não tiver sido feito)
$ npm run dev

PASSO 4: Acessar
----------------
• Frontend: http://localhost:5173
• Backend: http://localhost:8600
• API: http://localhost:8600/api

🐛 TROUBLESHOOTING RÁPIDO
================================================

Problema: "Port 8600 already in use"
Solução: $ lsof -i :8600 && kill -9 <PID>

Problema: "Cannot find module"
Solução: npm install

Problema: "Database connection refused"
Solução: $ mysql -u chat -p (verificar senha)

Problema: "CORS error"
Solução: Verificar URL do frontend em CORS do backend

Problema: "Mensagens não aparecem"
Solução: Verificar console (F12) do navegador

Veja OPERACAO.md para mais troubleshooting
